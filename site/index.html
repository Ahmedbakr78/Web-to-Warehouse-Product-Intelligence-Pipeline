Web-to-Warehouse Product Intelligence Pipeline

Compliant web ingestion, a Kimball warehouse on two SQL dialects, and a dashboard. A DEPI data-engineering graduation project: a compliance-first crawler feeds a Kimball star schema on PostgreSQL and MySQL, twelve data-quality rules score every load, and 113 REST operations with a React dashboard make the result explorable.

What it does

Six phases, each one measured and reversible.

1Retrieve

robots.txt gate, token-bucket rate limit, circuit breaker, response cache, per-request audit

2Clean

29 normalisation steps, 18+ currency formats, offline FX table, fixed vocabularies

3Load

resumable staging, then idempotent dimension and fact merges on natural keys

4Detect

price changes banded by magnitude, new/removed/recategorised events, catalog reconciliation

5Quality

12 rules across 6 dimensions, weighted score persisted per run, 90-day trend

6Serve

113 REST operations, 20 dashboard screens, CSV/JSON exports, read-only query lab

Run it

Six commands from a clean checkout to a populated dashboard.

make up && make db-waitBring the stack up
make bootstrapCreate the schema
make demo-postgresLoad the demo dataset
make run-pipelineRun the pipeline
open http://localhost:5173Open the dashboard
make checkVerify everything
